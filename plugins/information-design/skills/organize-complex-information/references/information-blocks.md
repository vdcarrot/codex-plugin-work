# 信息块与验证参考

按当前困难读取相应部分，无需为每次任务填满所有栏目。这里的示例是假定材料，不是其他项目的规则。

## 从整体形成阅读入口

整体说明应建立一个可继续展开的模型，而非把每章各缩成一句话。选取与材料相符的组织轴：

| 材料的核心关系 | 可采用的整体入口 | 应同时保留的关联 |
| --- | --- | --- |
| 多方共同完成任务 | 目标、职责、对象交接及完成判据 | 共享约束、并行分支、局部与整体完成的区别 |
| 多种条件决定结果 | 核心问题、决策维度、路径对照 | 条件组合、例外、不支持或尚不确定的情况 |
| 概念相互依赖 | 核心概念及其解释能力、必要前置知识 | 跨主题依赖与共同基础，避免重复定义 |
| 多个论点支持结论 | 总问题、主张、论据关系及结论边界 | 反例、分歧、证据限制与尚未解释之处 |

用读者问题测试组织轴：读者能否解释各部分为什么存在、共同回答什么？如果只得到一个新的章节列表，继续寻找部分之间的关系。

## 信息块记录

以下内容可写成短文、表格或结构化记录。记录内部标识符只在需要映射和维护时使用，不强制出现在阅读正文中。

| 记录项 | 用途 |
| --- | --- |
| 当前问题 | 写成读者能够提出、且有明确答案边界的问题 |
| 核心结论 | 简洁答案，以及会改变它的必要条件 |
| 全局作用 | 在整体模型中的角色，与其他问题的关系 |
| 前置知识 | 少量必要概念及定位入口；缺少时先教会它 |
| 必须共同理解的内容 | 相关概念、输入、条件、论据、比较、动作与结果；按材料选择 |
| 关键限制与不确定性 | 适用范围、重要例外、分歧及未证明的部分 |
| 深入内容 | 完整规则、推导、字典、算例、证据等 |
| 来源与关联 | 来源定位、依赖、对照及返回整体的位置 |
| 理解题 | 能检测解释、判断、整合或条件变化的问题 |

判断信息块的完整性时，先声明任务与已知输入。例如，“给定路径解释价格”与“判断该走哪条路径并计算价格”需要不同的内容边界。不能把后者需要的选路条件当作无须说明的前提。

## 合并、拆分与披露的判断

| 观察 | 调整 |
| --- | --- |
| 读者需要同时比较几种条件才能选择 | 共同呈现比较维度、结果与不适用范围 |
| 去掉某个限制会使当前答案错误 | 限制紧邻核心结论，其完整推导可深入 |
| 两段材料只是词汇接近 | 按各自问题分块，连接必要概念 |
| 同一块包含几个互不依赖的任务 | 分块，保留共同背景及相互作用 |
| 理解一块要反复翻找几个隐藏条件 | 调整边界或前置说明，增加链接只是辅助 |
| 上层说“必然”，下层才说“仅满足某条件” | 修正上层，保持跨层结论一致 |
| 来源对同一概念采用不同名称或定义 | 先区分同义、异义、场景差异或真实冲突，再组织 |

完整信息体系可以有层级学习入口与跨块连接。内容包含不等于执行顺序，知识依赖不等于因果；图中需要多类关系时，用明确标签或分开视图表达。

## 长 PRD 重组示例

假定一份文档协作产品的 PRD 将以下要求分别放在“编辑器”“审核”“权限”“版本”章节：

- 编辑者可以修改草稿，普通读者只看到已发布版本。
- 草稿由负责人审核后发布，发布生成一个新的不可修改版本。
- 草稿后续继续修改，不立即改变已发布内容。
- 文档撤回后不再对普通读者开放；材料没有说明离线副本如何处理。

整体入口可以说明：**协作产生草稿，审核发布形成面向读者的版本，权限与撤回决定其可见范围。**“继续编辑”和“读者已看到更新”是不同的结果；离线副本的撤回效果仍待确认。

围绕“编辑完成后，为什么普通读者还看不到改动？”组织一个块：

1. **全局作用：** 解释协作成果如何进入正式阅读范围。
2. **共同条件与因果：** 修改作用于草稿；只有审核发布才形成新的阅读版本；已发布版本不会因继续编辑而变化。
3. **关联限制：** 发布不代表所有情况下都可阅读，还受权限与撤回约束；提供相关块入口。
4. **按需深入：** 精确权限表、版本字段和审核表单，使用原资料中的定义与来源。

“撤回后离线副本是否不可读？”需在撤回块中明确为待确认，不能为使流程顺畅而补成已支持。此例只演示组织方式，不应将这套对象或流程移植到其他材料。

## 来源与覆盖映射

需要全量交付或长期维护时，维护简明映射：

| 来源位置或范围内问题 | 需要保留的主张、条件及例外 | 重组位置 | 状态或缺口 |
| --- | --- | --- | --- |
| 原资料稳定章节、编号或链接 | 保留语义，不仅记录相近名词 | 信息块与深入位置 | 已解释、待确认或有理由排除 |

一项来源可以支撑多个块，一个块也可以汇合多处来源。共用主张统一维护，引用处补充当前作用。来源变更后，同时检查整体结论、局部块、对照表和理解题，避免只有深入资料更新。

## 验证理解

先选定与读者任务一致的问题与参考判据，再进行两种检查：

- 仅提供上层核心说明，检验整体关系、主要判断和关键限制是否已经可见。
- 允许逐步深入，检验原因、精确规则、条件变化、跨块整合和依据定位。

记录首次足以作答的位置、外跳查找的必要条件与反复往返处。答对但需要拼接多处隐藏前提，仍应检查信息组织。

问题应覆盖不同能力，而非只要求复述：

- 解释一块为何对整体目标必要。
- 比较两种看似相近的条件，为何导致不同结论。
- 改变一个前提，指出受影响与不受影响的部分。
- 区分已经确定、需求期望与材料尚未说明的结论。
- 找到某个限制的来源及适用范围。

独立审阅者先只看成品与题目，不提前获得参考答案或整理笔记。复杂任务可再从未用于构造题目的材料或读者问题中抽样挑战，寻找同源遗漏；这仍是对提供资料的检查，不能代替外部事实核验。
